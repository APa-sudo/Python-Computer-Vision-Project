# OpenCV Experiments

## Overview

This directory contains a collection of small experiments and practice programs created while learning the fundamentals of OpenCV. These exercises were used to build familiarity with image processing concepts, camera handling, drawing utilities, and real-time computer vision workflows before developing the final gesture recognition system.

## Topics Explored

### Image and Video Processing

* Reading and displaying images
* Capturing video from a webcam
* Processing video frames in real time
* Saving images and video streams

### Drawing and Visualization

* Drawing lines, rectangles, circles, and polygons
* Rendering text on images
* Creating overlays and visual feedback elements

### Image Transformations

* Image resizing
* Cropping and region-of-interest selection
* Image rotation and scaling
* Color space conversions

### Real-Time Processing

* Frame-by-frame analysis
* Performance considerations
* Camera stream handling
* User interaction through keyboard controls

## Purpose

The experiments contained in this folder served as a foundation for understanding OpenCV's functionality and provided the necessary knowledge required for developing larger computer vision applications, including the real-time hand gesture recognition project contained in this repository.

## Technologies

* Python
* OpenCV

## Notes

These files represent exploratory and learning-oriented work. Some scripts may demonstrate isolated concepts, while others combine multiple OpenCV features to investigate practical computer vision workflows.
